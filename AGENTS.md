# Правила работы

- Работать только в папке этого проекта. Перед изменениями читать текущие файлы и учитывать уже реализованное поведение.
- Делать только ту функцию, которую просит пользователь. Не добавлять незапрошенные возможности и не ломать уже работающие функции.
- Использовать только обычные HTML, CSS и JavaScript. Не использовать npm, фреймворки и внешние ресурсы, включая CDN, сторонние шрифты и библиотеки.
- Данные пользователя должны оставаться в браузере. Ничего не отправлять в интернет.
- Делать понятные подписи к полям и кнопкам. Поля и кнопки должны иметь размер не меньше 44 × 44 px. Обеспечивать работу с клавиатуры и удобство на телефоне.
- Показывать деньги с пробелами между тысячами и символом тенге: `15 000 ₸`. Пустые и неверные числовые значения считать нулём. Никогда не показывать `NaN`.
- Не запускать git и ничего не публиковать без прямой просьбы пользователя.
- После работы перечислять изменённые файлы и объяснять, как проверить результат.
