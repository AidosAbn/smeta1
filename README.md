# Смета за 5 минут

Веб-приложение для быстрого составления сметы или коммерческого предложения с сохранением результата в PDF.

На текущем этапе реализована смета с автоматическим расчётом, скидкой, НДС и выбором валюты. Сохранение в PDF пока не реализовано.

Приложение предназначено для:

- предпринимателей, которым нужно подготовить коммерческое предложение клиенту;
- офисных сотрудников, которым нужно составить смету закупки или показать расходы руководителю.

## Файлы проекта

- `index.html` — структура страницы: поля сметы, список позиций, итог и кнопки действий.
- `styles.css` — оформление, удобные размеры элементов и адаптация для телефона.
- `script.js` — расчёт позиций, скидки, НДС и итога, смена знака валюты, добавление и удаление строк, установка сегодняшней даты.

Приложение работает на обычных HTML, CSS и JavaScript без установки зависимостей. Данные пользователя остаются в браузере и не отправляются в интернет. После обновления страницы введённые данные сбрасываются.

## Как открыть

Дважды щёлкните по `index.html` — страница откроется в браузере. Установка программ, сборка и запуск сервера не нужны.

## Как проверить

В первой строке введите количество `2` и цену `15 000`. Нажмите «+ Добавить позицию» и во второй строке введите количество `1` и цену `8 000`:

| Позиция | Количество | Цена | Сумма |
| --- | ---: | ---: | ---: |
| Первая | 2 | 15 000 ₸ | 30 000 ₸ |
| Вторая | 1 | 8 000 ₸ | 8 000 ₸ |

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.

Затем введите скидку `10` и НДС `10` (учебные значения):

| Строка итога | Сумма |
| --- | ---: |
| Сумма | 38 000 ₸ |
| Скидка | 3 800 ₸ |
| Сумма со скидкой | 34 200 ₸ |
| НДС | 3 420 ₸ |
| Итого к оплате | **37 620 ₸** |

Скидка считается от суммы позиций, НДС — от суммы со скидкой. Денежные суммы округляются до целых на каждом шаге расчёта. Строки «Скидка», «Сумма со скидкой» и «НДС» скрыты, если соответствующая сумма равна нулю.

Выберите по очереди `₸`, `₽`, `$`, `€`: знак должен измениться во всех суммах. Выбор валюты меняет только обозначение, без конвертации по курсу.

Пустые и неверные числовые значения должны считаться нулём. На странице никогда не должно появляться `NaN`.

Дополнительно проверьте:

- Суммы меняются сразу при вводе, без кнопки «Рассчитать».
- После добавления позиции кнопкой или Enter в поле последней строки курсор оказывается в названии новой позиции.
- Кнопка ✕ удаляет строку и обновляет итог. При удалении последней строки остаётся одна пустая.
- На экране шириной до 640px позиции выглядят как карточки с подписями к полям.
- Клавиша Tab переводит фокус между полями и кнопками; Enter и пробел активируют кнопки.
